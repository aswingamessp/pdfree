If one or both boxes stay empty — the checklist

  1. Press F12 → Network tab → type bauval in the filter → reload this page.
    • Request shows red "blocked" (by client / devtools) → an adblocker in your browser is blocking it. Disable the blocker for this site and reload — this is the most common cause.
    • Request shows 403 or fails → Adsterra is not serving yet. Check the Adsterra dashboard: Websites → pdfree-one.vercel.app must be Active (not "Under review"), and Ad Units must be active. New sites usually get reviewed within hours.
    • Request shows 200 but boxes empty → wait 1–2 hours; fresh units can be slow to first impression, and some geo locations get no fill.
  2. Ads never show to the person who owns the site in some setups — always test in a private/incognito window too.
  3. Never click your own ads — that risks a permanent Adsterra ban.
